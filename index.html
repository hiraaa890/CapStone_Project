1.  Maze Escape Game

A Java Swing-based maze game designed to combine graphical user interface development with Data Structures and Algorithms. The player navigates through a maze while the program uses different searching techniques to explore possible paths.

Built With: Java, Java Swing, Data Structures & Algorithms

Key Features:

  • Multiple difficulty levels: Easy, Medium, and Hard.
  • Uses BFS (Breadth-First Search) to find the shortest path.
  • Uses DFS (Depth-First Search) to explore paths through the maze.
  • Displays visited cells and path information.
  • Includes an undo feature for player movements.
  • Provides Play Again and Exit options.



2.   Lab Equipment Booking & Damage Tracking System

A database management project developed to organize and manage laboratory equipment and its related activities. The system is designed to keep track of equipment, users, bookings, returns, damage reports, and maintenance records in a structured database.

Built With: Oracle SQL, SQL Developer

Key Features:

  • Stores information about laboratory equipment.
  • Manages staff and user records.
  • Handles equipment booking and return information.
  • Records damaged equipment and damage reports.
  • Keeps track of equipment maintenance.
  • Connects related information through database relationships.



3. Java Number Guessing Game

A console-based number guessing game developed in Java where the player attempts to guess a randomly generated number within a limited number of attempts. The game includes different levels, score calculation, user input validation, and feedback based on the player's guesses.

Built With: Java, Scanner, Random

Key Features:

  • Generates a random number for each level.
  • Gives the player a limited number of attempts.
  • Provides feedback on whether the guess is higher or lower.
  • Calculates scores based on successful attempts.
  • Handles invalid user input.
  • Includes multiple levels with separate scoring.
