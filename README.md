# CapStone_Project
Portfolio Website

A functional, standalone 3-page personal portfolio website built from scratch using HTML5. This project demonstrates the use of semantic HTML elements, structured content, accessible forms, and data tables.

Pages:

index.html — Professional overview, biography, featured projects, and core skill sets.
achievements.html — Educational background, career milestones, and a structured data table 
contact.html — Accessible inquiry and outreach form .
